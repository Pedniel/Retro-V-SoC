# Prerequisites:

Install [yosys](https://github.com/YosysHQ/yosys/tree/main) and [xdot](https://github.com/jrfonseca/xdot.py).

These packages are commonly found in package manager. Fir example on arch-based distros they can be installed using pacman:

` sudo pacman -S yosys xdot`
